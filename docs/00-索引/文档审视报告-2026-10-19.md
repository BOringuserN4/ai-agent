## 三、主要发现

### 1. 图覆盖严重不足

审视前只有 `教学总览` 和 `番外` 有内嵌图；**核心章节 0 图**。
读者要从长文字里自己搭结构，成本很高。本次补到 **21/35** 有图。

### 2. “打个比方”几乎缺失

除了 `教学总览` 和 `精排层`，大多数章节没有生活类比。
本次给 9 篇核心章节加了“打个比方”，每篇一句，不喧宾夺主。

### 3. 学术腔是误报

结构扫描里的“摘要 / 关键词 / 参考文献”命中，基本都是技术词
（“关键词分组”“关键词命中”），**没有** `本文将` / `综上所述` 这类论文腔。
不需要清洗。

### 4. 调查类文档不适合硬套六段式

`显式规划`、`层级编排`、`辩论`、`黑板`、`合同网` 等是“问题 → 探针 → 结果 → 边界”，
硬套“是什么/结构定位/为什么/代码”会变成八股。
`teaching-doc` skill 已把“调查类模板”单列，保持现状即可。

### 5. 过时信息

`17 个模块` → `21 个业务模块`、`5000 行` → `4800 行` 已回写；
`v3` / `0.6` 仍出现在部分文档中，多数是历史实验语境。
`doc_freshness_check.py` 仍会报 **44 条 / 20 个文件**，**多数是合法语境**
（实验表、代码字符串、历史记录、本报告自身），不建议盲改；下次巡检时逐条判断。

## 五、还没做 / 下一批建议

按“教学收益 / 制作成本”排序：

1. **层级编排**：单 worker vs 工人池（慢工具 61–76%）。
2. **辩论调查**：正/反/裁决三角结构。
3. **精排层**：向量 vs rerank 的 failure mode 对比。
4. **MCP边界**：该不该做成 MCP 的决策树。
5. **记忆用例评测**：有/无记忆 4/5 vs 2/5 柱状图。

不建议给 `问题清单`、`历史归档`、`文档地图` 这类清单/索引硬塞图；
它们的功能是“查”，不是“讲”。

## 六、结论

> **图是拐杖，不是装饰。** 一张图只讲一件事；讲不清的地方，先改文字，再加图。
> 这次把核心章从“纯文字”补到“图 + 人话 + 数据”，
> 调查类保持“问题 → 探针 → 结果 → 边界”的骨架，不为了统一而统一。
